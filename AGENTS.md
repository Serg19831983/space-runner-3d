# СИСТЕМНЫЙ ПРОТОКОЛ И КОНТЕКСТ: CYBER RUNNER: APEX EDITION

## 1. Архитектура проекта (Жесткий стандарт)
- **Стек:** Чистый JavaScript (ES6+), Three.js (WebGL), Web Audio API, PWA (`index.html`, `three.min.js`, `manifest.json`, `sw.js`, `icon.png`).
- **Монолитное ядро:** Весь игровой движок, физика на `deltaTime` (60/120 FPS), Object Pooling (без утечек памяти), UI, звук и рекламный шлюз `AdsGateway` находятся в одном чистом файле `index.html`.
- **Среда разработки:** Работа ведется со смартфона через GitHub (и облачный деплой Netlify / PWABuilder для `.apk` / `.aab`).

## 2. Что уже реализовано в коде
- 3D-сцена: неоновая трасса, здания, 3 полосы движения, прыжки, быстрый спуск (Fast-Fall), управление с клавиатуры и свайпами/тапами.
- Боевая система: двойные плазменные бластеры (`F` / тап / кнопка ОГОНЬ), шкала энергии, разрушение препятствий, Босс-Дредноут каждые 400м с полоской HP и обстрелом.
- Мета-игра и звук: 4 уникальных 3D-корабля в Ангаре (`Viper`, `Phantom X`, `Titan Heavy`, `Omega Apex`), прокачка магнита/щита/плазмы, 4 цветовых биома, комбо за уклонения, процедурный Web Audio синтезатор музыки и SFX, шлюз рекламы `AdsGateway` («Второй шанс» и x2 награда).

## 3. Жесткие правила для ИИ-ассистента (НЕ НАРУШАТЬ)
1. **СТОП-ФИЧИ И БЕЗ ДРОБЛЕНИЯ:** Категорически запрещено предлагать десятки новых механик или дробить игру на множество отдельных `.js`-модулей (это вызывает конфликты и баги интерфейса).
2. **ТОЧЕЧНЫЕ ПАТЧИ:** Если нужно исправить баг, поправить мобильный UX или подключить SDK рекламы — выдавать правку строго в формате: `НАЙТИ СТРОКУ -> ЗАМЕНИТЬ НА` (либо выдавать `index.html` целиком при крупных правках, чтобы было удобно копировать со смартфона).
3. **АВТОНОМНОСТЬ ДЛЯ СТОРОВ:** Никаких внешних CDN-ссылок в релизе — `three.min.js` и `icon.png` подключаются локально для прохождения модерации и работы оффлайн.
4. **ФОКУС НА РЕЛИЗ:** Каждое действие должно вести к тестированию на смартфоне, сборке `.apk`/`.aab` (Netlify + PWABuilder) или публикации в веб-каталогах (Яндекс Игры).
