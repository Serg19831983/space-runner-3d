# Контекст проекта: 3D-игра на Three.js

## 1. О проекте
Браузерная 3D-игра (космический раннер/шутер) на чистом ES-модульном JavaScript + Three.js.
Разработка ведется со смартфона через GitHub.

## 2. Структура файлов в `src/`
- `main.js` — главный игровой цикл (`animate`), состояние игры (`window.isPlaying`), сцена и связывание модулей.
- `audio.js` — процедурный звук на Web Audio API (`createAudio`: эффекты `laser`, `coin`, `crash`, `shield`, фоновый бас, выключение на `KeyM`).
- `boss.js` — логика босса (`createBoss`: спавн каждые 500 ед. дистанции начиная с 450, движение по оси Z, HP = 100, состояния `escaped` / `killed`).
- `combat.js` — стрельба лазерами (`fireLaser`), сбор монет (`getCoins`) и проверка попаданий.
